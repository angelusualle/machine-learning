# Regression: Statistical Foundations & Decision Theory

Regression is the task of predicting a continuous random variable (label) $Y \in \mathbb{R}$ given an input vector $\mathbf{x} \in \mathbb{R}^p$. Under Decision Theory, our decision is selecting the predicted numerical value $\hat{y}$ that minimizes our expected risk.


To measure error, we adopt a standard loss function: **Squared Error Loss** ($L_2$ loss):

$$L(y, \hat{y}) = (y - \hat{y})^2$$

Squaring the residual guarantees a positive penalty and severely punishes large deviations (outliers). The expected value of this loss across the entire data-generating distribution is the **True Risk**:

$$R(f) = \mathbb{E}_{X, Y}[(Y - f(X))^2]$$

### The Bayes Optimal Regressor: The Conditional Mean
To minimize global risk across all points, we minimize the **pointwise conditional risk** for every specific input $x$:

$$\text{Conditional Risk} = R(f(x) \mid x) = \mathbb{E}_{Y \mid x}\left[(f(x) - Y)^2\right]$$

To find the optimal decision rule $f(x)$, we differentiate with respect to $f(x)$ and set the gradient to zero:

$$
\begin{aligned}
\frac{\partial R}{\partial f(x)} &= \mathbb{E}_{Y \mid x}\left[\frac{\partial}{\partial f(x)}(f(x) - Y)^2\right] \\
&= 2 \cdot \mathbb{E}_{Y \mid x}[f(x) - Y] = 0 \\
&= \mathbb{E}_{Y \mid x}[f(x)] - \mathbb{E}_{Y \mid x}[Y] = 0
\end{aligned}
$$

Because $f(x)$ is purely deterministic conditioned on $x$, $\mathbb{E}_{Y \mid x}[f(x)] = f(x)$. Therefore:

$$f^*(x) = \mathbb{E}[Y \mid X = x]$$

Under squared error loss, the **Bayes Optimal Regressor** is the **Conditional Mean**. Every regression model trained on Mean Squared Error (from simple OLS to deep neural networks) is fundamentally an attempt to approximate this conditional expectation surface.

> **Note on Alternative Losses ($L_1$ Loss):**  
> If we instead use **Absolute Error Loss** ($L(y, \hat{y}) = |y - \hat{y}|$), setting the derivative of the conditional risk to zero yields:
> $$P(Y \le f(x) \mid x) = 0.5 \implies f^*(x) = \text{Median}(Y \mid X = x)$$
> The Bayes Optimal prediction under $L_1$ loss is the **Conditional Median**. While this makes the model robust to outliers, $|y - \hat{y}|$ is non-differentiable at zero, making closed-form analytic solutions and smooth gradient descent more complex than least squares.


### Application of Maximum Likelihood (MLE)

Decision Theory proves that squared error targets the conditional mean. Maximum Likelihood Estimation (MLE) provides a principled framework to estimate the parameters of that conditional mean function by assuming an explicit physical noise model.

Assume our continuous target $Y$ is generated by a true deterministic function $f(X; \theta)$ corrupted by additive, independent zero-mean Gaussian noise:

$$Y = f(X; \theta) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$$

The class-conditional probability density function for observing a label $y_i$ given $x_i$ is:

$$p(y_i \mid x_i; \theta, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - f(x_i; \theta))^2}{2\sigma^2} \right)$$

Assuming $N$ independent observations, the joint likelihood function across the dataset is:

$$\mathcal{L}(\theta) = \prod_{i=1}^N \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - f(x_i; \theta))^2}{2\sigma^2} \right)$$

Taking the natural logarithm yields the Log-Likelihood:

$$\ln \mathcal{L}(\theta) = -\frac{N}{2}\ln(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^N (y_i - f(x_i; \theta))^2$$

To find the optimal parameter vector $\hat{\theta}_{\text{MLE}}$, we maximize this quantity:

$$\hat{\theta}_{\text{MLE}} = \arg\max_\theta \left( -\frac{N}{2}\ln(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^N (y_i - f(x_i; \theta))^2 \right)$$

Dropping additive constants and positive scaling factors that do not depend on $\theta$:

$$\hat{\theta}_{\text{MLE}} = \arg\max_\theta \left( -\sum_{i=1}^N (y_i - f(x_i; \theta))^2 \right) \equiv \arg\min_\theta \sum_{i=1}^N (y_i - f(x_i; \theta))^2$$

Dividing by $N$ gives the standard empirical **Mean Squared Error (MSE)** loss:

$$\hat{\theta}_{\text{MLE}} = \arg\min_\theta \frac{1}{N}\sum_{i=1}^N (y_i - f(x_i; \theta))^2$$


Thus, minimizing squared error is not an arbitrary heuristic—it is the exact Maximum Likelihood Estimator for the Bayes optimal conditional mean under an additive Gaussian noise model.
